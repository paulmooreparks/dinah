`TestEveryDeclaredAddressFormResolvesToTheEntityItNames` generates one example per entry of `addressform.Declarations()` from a fixture it builds through `runCLI`, runs each through the command that entry declares, and asserts both a zero exit and that the answer names the fixture entity the example was built from. For a `path` entry the asserted answer is that entity's own file path, so a resolver answering some other entity fails despite exiting zero; for the two `join` entries the asserted answer is the workstream's identifier standing in the card's membership afterwards. The example generator is a switch over the declared constant whose default arm fails the run. The test logs the number of forms probed and fails when that number is zero or differs from `len(addressform.Declarations())`.
