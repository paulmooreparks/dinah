A fresh agent given a workbench asked who it was and was told it was the operator, with nothing to indicate that this was a fallback rather than its own identity. It set an actor for everything afterwards; one that had not asked would have signed the operator's name to every act it took, permanently, in an append-only record, and would have been allowed to do things reserved to that seat. The tool knows which rung of the ladder answered, because it already reports that in the settings listing, so it can say so at the moment it matters. This card covers where that warning belongs and what it says, and whether the first act that writes to the record deserves it rather than only the command that asks.
