This is the widened form of dinah-425's open half, on the operator's instruction of 2026-09-07. That card repaired an instance and left the class; this one carries the class, and it covers documented behaviour as well as documented figures because both fail the same way.

The figure half, from dinah-425. The quick start prints a transcript of a real command and a guard holds the document to what the tool prints. Two cards each derived the count correctly, each from a real run on a real tree, and shipped a red trunk between them: one recorded 835, the other added keys, and neither could test against a trunk containing the other. The guard worked. Nothing ran it against the combination until after both halves had landed.

The behaviour half, contributed by another session working this board. A guidance passage took two review rounds over one sentence because the sentence had been reasoned rather than run. Executing it turned up an exit status that reports success in exactly the case that fails, and a second failure mode that is entirely silent. Both were invisible to reading and obvious to running.

The shape is one thing with the noun changed. A number carried without being re-derived on the tree it describes, and a behaviour described without being re-executed in the shapes it claims to cover. In each case the author was careful, the reasoning was sound, and the artefact was wrong because nothing forced a fresh run at the moment of publishing.

What is already decided and must not be re-opened. The operator ruled on 2026-09-07 that GitHub's branch protection requiring a branch to contain the current tip of its base before merging goes on, recorded as comment 7076 on dinah-425. That is his own act to apply and it is not this card's work. Note precisely what it covers: it stops an untested combination landing, which addresses the figure half's collision, and it does nothing whatever for a sentence describing a behaviour nobody executed. So the setting is a partial answer and this card exists because of the part it does not reach.

What this card has to settle.

Whether the two halves share a mechanism or only a diagnosis. A guard comparing a document against a tool already exists for figures and is why the figure half failed loudly rather than silently. Ask whether the same shape is available for behaviour, meaning something that runs a documented command in the shapes the prose claims and holds the prose to what came back, or whether behaviour can only be covered by a convention.

If any part of the answer is a convention, say so plainly and write it where it will be read at the moment it applies rather than in a document somebody consults beforehand. The board's own instructions already carry the figure half of this rule and both of the colliding cards followed it. That is the strongest evidence available that a convention placed where it was placed does not work, and a second sentence in the same place would be the third attempt at a fix that has already failed twice.

Do not let this card become an argument for generating the numbers. The quick start's block is a printed transcript so a reader sees what they would actually see, and a generated figure would satisfy the guard while teaching the reader nothing. The same caution applies to the behaviour half: a document that describes what a command does is worth more than one that quotes its help text back.

One piece of prior art worth reading first. Another session's token-cost document keeps every measured number inside a fenced block quoted from a real run, with no count or ratio in the surrounding prose. That is a stronger discipline than the quick start's and it may be most of the convention half of the answer.

Also still owed and not superseded by this card: dinah-425's failure-message improvement, so that a guard reporting a mismatch names the command to run and says the transcript needs recapturing, rather than leaving a reader to work out which of eight numbers moved.
