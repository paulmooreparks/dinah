note: Documented and accepted, and not deprecated. They are written down in the references guide, in one sentence beside the three words, saying that Dinah accepts them and never writes one back. Two reasons for documenting rather than merely tolerating. An input the tool accepts and does not describe is behaviour a reader can only discover by experiment, and this project's standing rule is that nothing rests on undocumented behaviour, which cuts the same way for the behaviour we publish as for the behaviour we consume. And the short forms are what every reference written before this card says, including one inside this repository's own compatibility fixture, so a reader meeting an old address needs the guide to tell them it still works. Deprecation is refused because nothing schedules a removal, and a deprecation notice with no removal behind it is noise on every page it appears on. The quick-start does not mention them, because it teaches one way to write a thing and the guide is where the second spelling belongs.
