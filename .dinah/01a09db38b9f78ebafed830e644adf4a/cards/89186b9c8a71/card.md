Asking to show a card without naming one prints a sentence with an empty gap where the card's name would go, and the gap now sits mid-sentence rather than trailing, so it reads worse than the sentence it replaced. The refusal-composition work established that a sentence with a slot nothing fills needs a second sentence written for the case where the value is absent, and it fixed that for the holder of a card; this is the same shape and the same repair, and it was left out only because the wording table had already been approved and the implementer would have had to invent a sentence nobody had ruled on. The repair is written out on the refusal card's own findings.
