One sentence covers every way a value can fail to parse, so it says the value is missing, empty, or will not parse whatever the actual cause was. Rename a workbench to a slug ending in a dash and a number and it says the slug is missing, empty or unparseable about a slug that is present, not empty, and parses fine; creating a workbench with the same name explains itself properly, so the tool gives two different accounts of one mistake depending on which command you typed. The refusal-composition work established that a refusal carries the reason it was raised for rather than a sentence covering every reason at once, and this is the remaining place that predates it. Every command that raises this refusal is affected, so the work is deciding how a cause reaches the sentence and then writing the causes down.
