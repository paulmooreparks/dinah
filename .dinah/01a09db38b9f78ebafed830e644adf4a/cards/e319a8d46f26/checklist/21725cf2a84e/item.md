note: "This is the structural answer to round 2, and it replaces four separate patches. The reviewer could not make the reconciling report lie, and then walked around it four ways: a declined prompt with no constructor, the drag handing a count back to a caller, the host switch keyed on survivors rather than targets, and a special case in §4 that showed nothing where the summary spoke. Every one of those was a route to the reader that did not pass through the construction, and patching them one at a time leaves the fifth to be found by the next reviewer. The question to ask of any route that ends in a message is where its report comes from and what stops a future route from skipping the construction, and a rule depending on each caller remembering to build one is the same shape D-13 already replaced once on this card when the counts came off the callers. Two mechanisms, and neither is a convention. `runBulk` performs the resolve, the prompt, the host choice, the loop, the checkpoints, the channel lines and the message, so a command supplies rows and an act and nothing else; the host switch then reads `rows.length`, which is the targeted count and the same number the summary's single-row case reads, so the per-row toast and the summary cannot both fire. And `reportMark` is an unexported symbol every report carries, so a hand-built literal cannot obtain one and `summaryFor` refuses it before the reconciliation arm even runs. AC-25 pins the mark in both directions and pins that the symbol stays unexported; AC-26 pins that `summaryFor` and `collectingHost` each have exactly one caller in `src/`. What this does not close is a command calling `vscode.window.showWarningMessage` itself, and the reason it does not have to is that only `extension.ts` imports `vscode` in the whole of `src/`, verified by search at 4c33c2c, so a command module holds no handle to the editor but its `CommandHost`. The cost is that a command can no longer choose its own reporting, which is the point: three routes reach the reader, §3a names all three, and a fourth is visibly a fourth."
