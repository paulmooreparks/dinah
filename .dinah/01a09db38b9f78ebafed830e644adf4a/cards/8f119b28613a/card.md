The operator wants a set of dinah.-prefixed extension kinds for concepts that do not belong in the core contract but are obvious deliveries: gates, lanes, personas, spend tracking, templates, and later the beta/dev cut discipline. The dot-named extension namespace already supports it; the design work is reserving the prefix as first-party, choosing the initial kind set, writing each kind's specification and method text, and deciding which rungs of the processing ladder each kind needs. The library doubles as the proving ground the format design's promotion path expects.
