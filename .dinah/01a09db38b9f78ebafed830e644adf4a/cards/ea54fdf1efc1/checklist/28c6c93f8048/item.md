Every affordance a tool response publishes names a tool this head serves. `internal/mcp/mcp_test.go`, `TestEveryToolResponseCarriesAffordances`: its call table gains a `get_field` row and a `set_field` row, and inside its existing loop each response's `affordances` member is decoded and every name in it is required to be a name the head's own `tools/list` answer carries. The served set is read from a `tools/list` call made in the same test rather than written out. A response whose `affordances` member is an empty list fails rather than passing, and the run is fatal when the call table is empty or when `tools/list` returns no tool. A failing run names the tool called, the offending affordance, and the served names.
