title: Asking a workbench for a field it does not have offers the wrong list
column: 5ea2db0272fc
state: ready
severity: major
priority: next
---
Naming a field the workbench command does not carry refuses with a list of four names, and all four belong to a different command entirely: they are the personal settings rather than the workbench's own fields. A reader who does exactly what the message says, and names one of the four offered, is refused again by the same message. Omitting the field name is worse: the sentence renders with an empty gap where the name should be. The correct list is the three fields the bare command already prints, so nothing has to be invented, and the refusal should point at the command that shows them.
