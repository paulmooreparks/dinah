The guard's false-positive rate is measured over a corpus of correct code it must stay silent on, and the measurement ships as a test rather than as a figure in a pull request. This is the criterion five design reviews were paying for. Every defect found in those five rounds was a branch that condemned correct Go with no instance anywhere in this repository, so a run over this repository cannot falsify the guard, and the sixteen hand-written sources of the companion criterion cannot either, because each one was written by somebody who already knew which branch they were testing. The corpus is a body of Go large enough that a wrong branch has an instance in it, and which has been ruled correct with respect to the five rules by a reading that is recorded rather than assumed. Which body of code that is, and how each of its directory reads was ruled correct, is this card's central design question and is settled in its spec rather than here; what this criterion fixes is that a corpus exists, that it is named in the test, that the test asserts how many files and how many call sites the sweep read over it so a corpus that read nothing cannot pass, and that the sweep draws zero findings over it. A finding drawn over the corpus fails the test, and the pull request records which of the two it was: a branch in the guard that condemns correct code, or a genuinely swallowed read in the corpus that has to be ruled on and recorded before the corpus can be used. A corpus assembled by taking whatever the guard is already silent on is the failure mode here, so the ruling on each of its reads is made before the guard is run over it, and the record of that ruling is what the reviewer reads rather than the silent run.
