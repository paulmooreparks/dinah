Working with Documents

Markdown files open in Docs, where you can edit the document or its text. Plain text files open in Editor. The View menu changes how you read and edit the file.

Use File, Save to keep your changes in the file. Save As, in File or Document, chooses another name or folder. The title shows the file name and a dot when you have unsaved changes.

This window works with files on this computer. Publish is available in the main window for a document whose source supports it.

The status line shows the document name, language and editing position. Help, Keyboard Shortcuts lists the current commands. Key Bindings lets you change the editing keys.

A saved file keeps its unsaved draft for recovery when you reopen it. Save a new document before closing its window. Closing asks about unsaved changes.
