dinah-372 candidate review, round 1

Four sidebar mask candidates and four colour icon candidates are below, and the choice is one of each. The two grids are independent, so the silhouette you like best and the colour treatment you like best do not have to carry the same number.

This page is one self-contained document. Every candidate is embedded in the file itself as a base64 data: URI, so it opens from anywhere on disk with no server, no network and no sibling files. Each embedded payload is the byte-for-byte content of the corresponding mask-N.svg or color-N.png committed on the card's branch, so what you are looking at is what would ship.

The tints, backgrounds and icon sizes used below were read out of an installed VS Code 1.136.1 rather than assumed. The comment at the top of this file's style block names the files they came from.

Sidebar mask candidates, in the activity bar

VS Code paints an activity bar icon as a mask, which discards every colour in the source and repaints the shape in the theme's own tint. Each candidate appears twice per column, first in the selected tint and then in the unselected one. Both default dark themes are shown because they tint differently, and both icon sizes are shown because VS Code uses 24 pixels in the ordinary activity bar and 16 in its compact one. The 96 pixel rendering on the right is there so you can see what the drawing is, and it is not a size the activity bar ever uses.
