What this is

  • It opens by itself once for everyone, at the first start of the version that has it, and Skip Set-Up or the close button leaves at once with today's defaults. Help, Set Up Dinah opens it again whenever you like.
  • Step 1 says what the product can really tell, which is whether each agent's program was found. Choosing one tests its connection, and the row then says Answers or gives the reason it does not. Choose Codex, see it fail, press Sign In and see it answer.
  • How to Install opens the page with that agent's install instructions in the browser. Another product built on this one can point it at its own page.
  • Step 2 is the guide, speaking through the agent chosen. Each of its five questions has its choices as a list. Choose one and press Continue.
  • The question about what the agent asks before it acts offers the chosen agent's own choices, in the words Settings uses. Choose Ollama in step 1 to see a different list. Antigravity has no such setting, so with it the question is left out.
  • It asks what the agents should call you, offering the name of this computer's account, no name, or a name you type.
  • Or say it in your own words. Type "I write requirement documents for a client in C:\Work\Pricing and I want to be asked before anything runs" and press Say. The guide takes every answer it can from that, says which, and asks only what is left.
  • Step 3 shows every setting before anything is set, with where each value came from. Change goes back to that question. Set It Up sets them. Undo, which takes its place, puts them back. Two rows say what Undo cannot take back: a sign-in stays, and the background questions are turned off again.
  • The question about answering small questions in the background is the one the Judgements item in the tray asks today. Asked here, it is not asked a second time.

What is scripted here

  • The guide's reading of your own words is done by matching words. In the product the model reads them.
  • Choose a Folder would open the folder dialog. Here it takes C:\Work\Pricing.
