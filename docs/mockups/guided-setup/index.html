What this is

  • It opens by itself at the first start, and Skip Set-Up or the close button leaves at once with today's defaults. Help, Set Up Dinah opens it again whenever you like.
  • Step 1 has no model in it. It lists the agent programs found, says which are ready, and offers the one thing to do about each that is not. Press Sign In on Codex to see a row become ready.
  • Step 2 is the guide, speaking through the agent chosen. Each question has its choices as a list. Choose one and press Continue.
  • Or say it in your own words. Type "I write requirement documents for a client in C:\Work\Pricing and I want to be asked before anything runs" and press Say. The guide takes every answer it can from that, says which, and asks only what is left.
  • Step 3 shows every setting before anything is set, with where each value came from. Change goes back to that question. Set It Up sets them. Undo, which takes its place, puts every one back.
  • The question about answering small questions in the background is the one the Judgements item in the tray asks today. Asked here, it is not asked a second time.

What is scripted here

  • The guide's reading of your own words is done by matching words. In the product the model reads them.
  • Choose a Folder would open the folder dialog. Here it takes C:\Work\Pricing.
