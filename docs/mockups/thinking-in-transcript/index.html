Thinking shown in the transcript

Mockup, 20 November 2026. Change the controls, then press Run a Turn.

What is proposed

  • With Show Thinking on, each thought is a row of the transcript, where it arrived, between the agent's messages. Nothing has to be opened to read it.
  • The Working block keeps the tool calls only, and still starts closed.
  • With Show Thinking off, no thought is shown anywhere, as today.
  • A thought row is flat and muted, so an answer still stands out from it.
  • The rule is the same for every agent program. A program that sends no thinking shows none, and the chat does not pretend otherwise.

What it costs

  • A transcript is longer with the setting on. One agent program in use sends more thoughts than answers. The setting is the way to have less.
  • The second design adds nothing to the transcript, but it shows only the newest thought and only while the turn runs. To read the earlier ones the block is opened, as today.
