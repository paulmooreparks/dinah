A suggested reply in the prompt box

Mockup, 19 November 2026. Click in the box and press Tab.

Tab

What it does

  • When a turn ends and the chat waits for you, a judge reads the end of the conversation and proposes what you might say next. The proposal appears in the empty prompt box in the placeholder's colour. It arrives a moment after the turn ends, and nothing else on the screen changes when it does.
  • Tab makes it the box's text, with the caret at its end, and Send comes alive. Nothing is sent until you send it.
  • Esc drops the suggestion, and the ordinary placeholder returns. So does a new turn, which makes the suggestion out of date.
  • Typing anything hides it. If you empty the box again before the next turn, it comes back.
  • When the judge has nothing worth proposing, the box shows its ordinary placeholder. The fourth case in the list above is one.
  • A long suggestion is cut to the two lines the box already has, so the box does not grow when it arrives. Tab gives you all of it. The third case shows this.

Why it is built this way

  • The suggestion is never the box's text until you take it. The box's text is saved as your draft, goes into your prompt history and enables Send. A suggestion that was only drawn there can do none of that by accident.
  • It is drawn over the box, and is not the placeholder itself. The prompt box sizes itself to its placeholder when it is empty, so a long suggestion set as the placeholder would make the box jump taller as it arrived.
  • Only Tab takes it, and Enter does not. Claude Code also sends a suggestion on Enter. Here an empty box and Enter does nothing today, and a suggestion that could be sent by one stray key is a message you did not write.
  • It follows the judgement agents' rule that a judge never interrupts. It shows only in a box you are already looking at, opens nothing and moves nothing.

Alternatives

  • No key cap. The second choice under "How Tab is shown". It is the plainest and matches Claude Code, which shows nothing. Someone who has not been told cannot find out that Tab does anything, which is why I recommend the key cap.
  • A button beside the box ("Use Suggestion"). It would be easy to find, and it would have to appear and disappear with the suggestion, which moves the row.
  • A row of two or three short replies above the box, as phone keyboards have. It gives a choice, and it costs a row of the chat and one more call or a longer answer each time.

What Tab stops doing

  • Tab moves to the next control today. While a suggestion shows it takes the suggestion instead. Shift+Tab still moves back, and after Esc, Tab moves on as before. With the list of skills or of mentions open, Tab still picks from the list, as it does today.
