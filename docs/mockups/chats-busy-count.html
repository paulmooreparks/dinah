What the count says.

  • The Chats tab shows how many chats are busy. A chat is busy while its agent is in a turn, and also while it has a background task or subagent running after its turn has ended.
  • The count covers every chat this window runs, in every open workspace, because the tab belongs to the window and not to one workspace. Changing the list between This Workspace and All Open Workspaces changes the list only; the count stays the same.
  • When every chat is idle the badge is gone, so an empty tab means nothing is running.
  • A chat that waits for you is counted by Notifications and sits under Needs You. It is not counted as busy.
  • The badge is the one the Notifications tab draws today. Its slot keeps the width of "99+" whether a count is shown or not, so the badge appearing, changing or going moves no tab and no title.
  • The Notifications tab itself does not keep such a slot today: when its count appears the tab widens by about 40 pixels and the tabs after it move. The status bar's Notifications button does keep one, with a hidden "99+" copy.
  • With All Open Workspaces chosen, the Working group lists the same chats the count counts, and its own count is the same number.
