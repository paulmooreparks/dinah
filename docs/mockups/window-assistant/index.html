Since You Last Looked
    What It Does

    Bottom bar and tray

    What changed from the second mockup

    • Nothing runs on a press. Pressing a task chooses it, and "What It Does" says what it would do to which windows, by name. Typing a request and pressing Ask does the same.
    • Run does it. Run is disabled until there is something to run, and again once it has run. After Ask, Run has the focus, so Enter a second time runs what you typed.
    • Undo is beside Run, in the foot, and puts the windows back as Run found them.
    • A question, such as What Needs Me?, is answered in the same place and has nothing to run.

    Try

    • Press Tidy Up, read which windows it would close, then press Run, then Undo.
    • Type "find all the windows for the pricing work", press Enter, read the answer, and press Enter again.
    • Press one task and then another without pressing Run. Nothing moves.
    • Open Edit Tasks and press Try It: it says what the words would do and does nothing.

    What is the same

    • The assistant is reached from the tray and a key only, and is one popover of one size.
    • Tasks are a list that scrolls, and Assistant Tasks is a window of its own with a starter set.
    • It can only do what you could do by hand in the window. Closing is limited to idle chats and documents with nothing unsaved.
