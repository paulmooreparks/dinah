    What changed from the first mockup

    • Finding by what you say. "Find all the windows for the pricing work" is the assistant's first job. Here it looks for your words in the stand-in windows' titles; in the product the model reads each window's title, workspace, sources and first lines, so the words need not be in a title. When nothing matches it says so, and never says it cannot look.
    • Tasks are a list that scrolls, in place of buttons. One press runs a task.
    • Assistant Tasks is a window of its own, opened with Edit Tasks. A task is a name and the words the assistant is asked. The list starts with a starter set, which you can change, reorder, delete, and restore.

    Try

    • Type "find all the windows for the pricing work", "show everything about the release", or "which windows are about tax?".
    • Type "put the documents side by side and the chat under them", or "close what is finished".
    • Open Edit Tasks, add a task such as "Pricing" asking "find all the windows for the pricing work", save it, and run it from the list.

    What is the same

    • The assistant is reached from the tray and a key only, and is one popover of one size.
    • Its answer is the thing done and one line that says what it did, with Undo.
    • It can only do what you could do by hand in the window. Closing is limited to idle chats and documents with nothing unsaved.
