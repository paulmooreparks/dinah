The model in Chats and the Org Chart

Mockup, 17 November 2026. Drag the Chats pane's lower right corner to change its width.

  • The model goes on the line that already shows the program, straight after the program's name, so no row and no card grows a line.
  • The name is the one the program itself gives the model, as in the chat's own model menu. Devin's "Adaptive" is shown as Adaptive, because that is what Devin reports; Dinah does not guess which model Adaptive picked.
  • An open chat shows the model it is running now and changes in place when the model is changed. A closed chat shows the model saved for it, which it gets back when it opens.
  • When the program offers no choice of model, or the saved choice has no name the program still lists, the model is left out rather than shown as a raw code.
  • The line is cut with an ellipsis in a narrow pane, as today, and its tooltip and the row's spoken label give the whole line.
