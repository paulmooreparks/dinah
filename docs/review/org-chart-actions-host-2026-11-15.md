The host supplies legal action representations and dispatches all six operations through the existing person-facing team, group, creation and Recycle Bin calls. Team precondition helpers are shared by the action query and the existing bus transaction checks. Tokens detect changed ownership or structure and grant no authority. Relation mutations share cleanup serialization; execution still enforces the existing bus checks. Unknown or held ownership and conflicting bus places offer no action. A local chat without a bus place can still enter the bin.

Create Team retains its committed group when conversion fails and returns that identity with recovery links and member outcomes. The internal composition callback permits a deterministic failure between those existing operations; the exported page call always supplies nil. It adds no product test route or caller-selected callback. Only Start a Chat may contact a provider. Creation is never automatically retried after an unknown outcome.
