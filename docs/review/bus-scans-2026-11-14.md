# Bus query scans

The candidate removes history scans from wake checks, attention capture and Decisions selection. It changes no retention policy and removes no stored rows. The original growth proposal remains unchanged.

Four partial indexes cover pending deliveries, human-delivery cursors, unread human deliveries and undismissed human deliveries. Their leading columns match the query constraints, so the planner can seek into the relevant range. The migration creates them after older databases receive the required columns. Existing indexes remain available to older builds.

Decisions candidates come from open structured requests and eligible human deliveries after the existing first-use boundary. The boundary and every closure predicate remain unchanged. Attention applies its cursor and ordering to the delivery's message ID, which equals the joined message's primary key. Wake uses its previous predicate against the pending-delivery index.

The additive tests compare the previous and current predicates on invented data, including cancellations, dismissals, duplicate deliveries, read state, replies and structured requests before the boundary. Query-plan checks require the bounded indexes. Existing tests are unchanged.

## Measurement method

The before and after runs use the same invented fixture and timing method as the growth note. Each query has one first call followed by 21 warmed calls. Complete returned values receive SHA256 hashes outside the timed interval. Identical row counts and hashes are required for every query at all three sizes. Both runs use the same enhanced harness, whose SHA256 is `2472deaa3448bb049ed2223540af3257b51a3b30d3e7940feba45774ea87c05e`.

The baseline is master `2886fdb1`. Candidate source is `2cb2c9f9c0b3fc4cf3472ecd501cafa5d82c0ee7`. The retained receipts contain first-call times, median times, p95 times, query plans and database sizes. Measurements exclude browser work, notification-file writes and contention. The fixture keeps the roster and outstanding work fixed as message history grows; it does not establish bounds for a growing pending backlog.
