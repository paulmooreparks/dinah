# Development practice

This directory holds the development practice for this repository: the prose
standard, the Go style standard, the rule for working safely against the
operator's own data, the translation staleness contract, and three collections
of convention counterexamples.

These documents were exported on 2026-09-14 from the Andoneer board that
Dinah's own workbench replaced. They live here as files because the workbench
has no documents concept, so the repository is the only place left that can
hold them.

The three counterexample files are large. They are meant to be searched by
heading when a specific convention is in question, not read end to end, and
putting them in files is what makes that search possible.
